# Iwish CRM 快速上手使用手册（内部使用）

> 面向对象：销售、销售主管、运营、管理员等业务同事，用于 **第一次上手系统**。
> 目标：10–20 分钟完成阅读 + 跟着操作一遍，即可独立使用核心功能。

---

## 1. 登录与账号状态

### 1.1 登录入口
- **访问地址**：请在浏览器输入管理员提供的系统网址，例如 `https://your-crm-domain.com`
- 建议使用 **Chrome / Edge 最新版**，手机浏览器也可使用。

### 1.2 注册账号
- 在登录页点击 **“创建账户 / 注册”**，进入注册页。
- 按页面提示填写：
  - **邮箱**：作为登录账号；
  - **密码**：至少 8 位，建议包含字母 + 数字；
  - **姓名（full_name）**：真实姓名，方便在团队内识别；
  - **手机号（phone）**：用于联系和风控。
- 注册提交后，系统会自动创建个人档案，状态为 **`pending（待审批）`**，并跳转到“等待审批”页面。

### 1.3 账号状态（很重要）
- **pending（待审批）**：
  - 只能看到“等待审批”提示；
  - 看不到任何业务数据（线索、公海池等）。
- **active（已启用）**：
  - 正常登录后可进入系统首页（仪表盘），
  - 可按分配的权限访问各模块。
- **disabled（已禁用）**：
  - 登录后会被立即登出，提示账号已被停用；
  - 通常发生在离职/长期停用场景，如有误请联系管理员。
- **rejected（已驳回）**：
  - 登录后会看到驳回原因；
  - 不能访问任何业务数据。

> **遇到问题怎么处理？**
> - 提示“正在等待管理员审批”：说明账号还未通过，联系团队管理员审批。
> - 提示“账号被禁用/驳回”：先确认是否有组织变动，再与管理员沟通，不要频繁重试。

## 2. 界面结构总览

登录成功且账号为 active 后，系统会进入主界面：

- 左侧：`Sidebar` 侧边栏
  - **仪表盘**：总览看板
  - **线索看板 / 我的线索**：个人/团队线索
  - **公海池**：未归属的线索池
  - **报表 / Analytics**：数据分析
  - **系统设置（仅管理员）**：组织与权限配置
- 顶部：`TopBar`
  - 当前组织名称、用户头像、退出登录等。
- 右侧主区域：根据当前菜单显示不同功能页面：
  - `Dashboard` / `LeadKanban` / `PublicPool` / `AnalyticsDashboard` / `SystemSettings`。

> 对普通销售，一般只需要熟悉：**仪表盘 + 线索 + 公海池** 三个区域即可开始工作。

## 3. 仪表盘（Dashboard）

### 3.1 能看到什么？
- **总线索数**：当前有多少条在管线索；
- **转化率**：线索转成成交的比例；
- **本月销售额**：按权限统计的当月销售额；
- **风险线索**：长时间未跟进、状态异常的线索数量；
- 销售漏斗、最近成交列表等概览数据。

### 3.2 如何使用？
- 仪表盘是 **只读视图**，用于：
  - 早上快速看今天/本周工作量；
  - 主管查看团队整体表现；
- 若发现数据明显不对（例如所有数字都是 0）：
  - 先确认是否当天刚开新账号、还没有线索；
  - 若已在 **公海池 / 线索** 中看到大量数据，但仪表盘仍为空，再反馈给管理员排查权限或数据问题。

## 4. 线索看板与线索详情

> 提示：线索模块的实际 UI 以当前系统为准，下文描述的是常见操作习惯。

### 4.1 线索列表 / 看板

- 在侧边栏点击 **“线索”**（或对应入口），可看到：
  - 按阶段分列的看板视图，或表格视图；
  - 可筛选：负责人、阶段、来源、时间、团队等；
  - 列表字段通常包含：线索名称、客户、负责人、阶段、最近跟进时间等。

常用操作：
- **搜索线索**：顶部搜索框输入客户名、公司名、电话等关键词；
- **按阶段查看**：在不同阶段列之间拖动卡片（若支持拖拽），即代表调整线索阶段；
- **新建线索**：点击页面上的“新建线索”按钮，填写客户信息并保存。

### 4.2 线索详情页

- 在列表/看板中点击某条线索，进入 `/leads/[id]` 详情页。

可完成的典型动作：
- 查看：基础信息（公司、联系人、渠道、预算等）、当前阶段、负责人；
- 记录跟进：添加电话记录、微信沟通记录、拜访记录等；
- 更新阶段：从“新线索”改为“意向”、“谈判中”、“成交”等；
- 关闭线索：标记为 **成交（won）** 或 **丢单（lost）**，并填写原因。

> **注意：**电话、邮箱、预算等字段有严格的读写权限控制。
> - 若你看到的是脱敏数据（如手机号中间是 ****），说明无敏感字段查看权限；
> - 若保存时提示“无权修改敏感字段”，说明当前角色未开通对应写权限，需要管理员调整权限配置。

## 5. 公海池（Public Pool）——核心使用指南

公海池是本系统的关键模块，用于统一管理 **无归属/被退回** 的线索。

### 5.1 进入公海池

- 在侧边栏点击 **“公海池”**；
- 若看到提示“当前账号无权访问公海池”，说明管理员未开通 `canViewPublicPool` / `leads.read` 相关权限，需要找管理员开通。

### 5.2 页面结构

公海池主界面大致分为四块：

1. **顶部标题区**
   - 显示“公海池”标题、当前公海线索总数。

2. **顶部操作按钮**
   - **分配给销售**
     - 仅对具有分配权限的账号显示/可用；
     - 需先勾选若干条线索，再点击按钮；
     - 弹出对话框选择目标销售，并可填写备注，确认后这些线索从公海池消失，分配给对应销售。
   - **认领到我的线索**
     - 选择一条或多条线索后点击，将线索认领到自己名下；
     - 认领成功后，这些线索也会从公海池列表中消失，出现在你的“我的线索”中；
     - 若提示“没有认领线索的权限”，说明 `leads.assign` 相关权限未开通。
   - **导入线索**
     - 打开导入对话框，支持上传 CSV 模板批量导入；
     - 支持拖拽上传或选择文件；
     - 系统会自动检查手机号重复并跳过重复条目；
     - 导入完成会生成导入任务记录，并写入审计日志。
   - **导出**
     - 可导出当前公海池线索为 **CSV / Excel（CSV 文件）**；
     - 导出过程会创建导出任务并写审计日志。

3. **筛选与搜索区**
   - 搜索输入框：支持按公司名称、联系人、电话搜索；
   - 预留“筛选”按钮，用于后续扩展更多过滤项。

4. **线索表格**
   - 列表核心字段：
     - 公司名称、联系人、电话、来源、预算、最后阶段；
     - 退回原因、最近退回人、池内天数；
   - 支持：
     - 勾选行进行批量操作；
     - 点击“更多”按钮查看详情、查看跟进历史、认领、分配、删除等。

### 5.3 公海池常见操作流程

#### 5.3.1 销售认领线索

1. 打开“公海池”；
2. 在列表中勾选要认领的一条或多条线索；
3. 点击顶部 **“认领到我的线索”**；
4. 完成后，提示“认领成功”，这些线索从公海池消失，在你的线索列表中可见。

> 若系统提示“没有认领线索的权限”：
> - 不要重复操作；
> - 联系团队管理员，在“系统设置 → 角色权限”中为你的角色开启对应权限。

#### 5.3.2 主管分配线索给销售

1. 在公海池勾选多条要分配的线索；
2. 点击 **“分配给销售”**；
3. 在弹框中：
   - 选择要分配的目标销售（可看到对方当前在跟进线索数量，避免过载）；
   - 选填备注（例如“本周优先跟进”、“高意向客户”等）；
4. 点击“确认分配”；
5. 系统会调用后台 RPC 完成分配并写审计日志，成功后这些线索从公海池消失。

#### 5.3.3 导入线索到公海池

1. 点击 **“导入线索”**；
2. 在弹框中：
   - 先点击“下载导入模板”，得到 `public_pool_import_template.csv`；
   - 用 Excel 打开模板，按列填入：公司名称、联系人、电话、微信、来源、预算等；
   - 保存为 **CSV 格式**。
3. 回到导入弹框：
   - 将文件拖入上传区域，或点击“选择文件”选择刚才的 CSV；
   - 系统会自动解析并检查手机号重复：
     - 模板内重复手机号会自动跳过计入“重复条数”；
     - 如果库中已经存在相同手机号线索，也会跳过以避免撞单。
4. 解析完成后，点击 **“确认导入”**：
   - 系统会为本次导入创建一条导入任务；
   - 将符合条件的行逐条写入公海池；
   - 完成后会弹出统计提示（成功条数 / 失败条数 / 重复条数）。

> **建议：**
> - 在导入前尽量规范化手机号（只保留数字），避免同一号码被系统误认为不同号码；
> - 导入文件中尽量保持一行一个线索，不要合并单元格。

#### 5.3.4 导出公海线索

1. 点击 **“导出 → 导出为 Excel / CSV”**；
2. 系统会即时生成 CSV 文件并触发浏览器下载；
3. 同时写入一条导出任务记录与审计日志。

> **数据安全提醒：**
> - 导出的文件包含客户电话等敏感信息，请按照公司数据安全要求存放与使用；
> - 不要随意通过个人微信/邮箱转发原始数据文件给外部人员。

## 6. 系统设置（管理员视角）

> 该部分仅供需要配置组织与权限的管理员参考，普通销售可忽略。

系统设置页面（`SystemSettings`）大致包括：

- **待审核列表**：
  - 查看所有 `pending` 用户；
  - 执行“审批通过/驳回/禁用/恢复”等操作（底层通过 RPC 完成，并写审计日志）。
- **组织架构（Teams / Roles / Profiles）**：
  - 管理部门、角色、成员归属；
  - 变更成员所属团队或角色时，会影响其能看到的线索范围。
- **角色权限矩阵**：
  - 为不同角色配置权限点（如 `leads.read`、`leads.assign`、`leads.export` 等）；
  - 配置数据范围（self / team / org / custom）。
- **用户覆盖权限**：
  - 在特定时间段内临时给某个用户增加或收回权限；
  - 支持设置过期时间和原因；
  - 所有变更都会写入审计日志。
- **字段策略（Field Policies）**：
  - 指定哪些字段需要敏感读写权限（如手机号、邮箱、预算等）；
  - 设置脱敏规则（例如手机号中间打星）。
- **审计日志（Audit）**：
  - 查看审批、分配、转移、删除、导出等敏感操作记录；
  - 支持按时间/操作人/对象等条件筛选。

> 管理员修改上述配置后，无需发版，权限与范围会立即生效。

## 7. 常见“被拒绝”场景与处理方式

系统绝大多数安全控制由后端强制执行，前端仅做友好提示。遇到以下情况属于正常保护行为：

- **访问公海池时提示“无权访问公海池”**
  - 说明没有 `leads.read` 或公海访问相关权限；
  - 请联系管理员在“系统设置 → 角色权限”中配置。

- **点击“认领/分配/删除线索”时提示“没有 xxx 权限”**
  - 说明当前角色未开通对应操作的权限点（如 `leads.assign`、`leads.delete`）；
  - 先确认业务上是否确实需要此权限，再由管理员视情况开通。

- **看不到完整手机号/预算，只看到脱敏数据或空值**
  - 说明未开通敏感字段访问权限（如 `leads.fields.read_sensitive`）；
  - 在确有业务必要时，由管理员统一评估后开通。

- **导出失败并提示权限错误**
  - 说明未开通 `leads.export` 或 `reports.export`；
  - 由于导出行为风险较高，通常只授予管理岗或合规指定人员。

## 8. 数据安全与使用规范（务必转告同事）

- **不要将导出的线索文件放在个人网盘/公开共享目录**；
- 不要通过未经批准的工具（个人邮箱、社交软件）向外部分享线索文件；
- 在线索备注中，仅记录与业务相关的必要信息，避免录入过多敏感隐私；
- 发现账号异常登录或数据异常变动时，及时告知管理员；
- 离职或岗位变动时，按照公司流程办理账号禁用 / 交接，避免自己手动大量导出数据。
